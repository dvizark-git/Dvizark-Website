# Portafolio — [Tu Nombre]

Sitio web de portafolio alojado en GitHub Pages para mostrar proyectos de **Cómic**, **Ilustración**, **Concept Art** (Personajes, Entornos, Criaturas y Props) y **Diseño Gráfico**.

## Estructura del proyecto

- `index.html`: Estructura principal de la página.
- `css/styles.css`: Estilos, variables de color y tipografías.
- `js/main.js`: Filtrado de categorías y subcategorías del portafolio.
- `LICENSE`: Licencia MIT aplicada únicamente al código fuente de la plantilla.

## Nota de derechos de autor

La licencia MIT de este repositorio aplica al código de la web, **no** a las ilustraciones, cómics, diseños ni demás obras artísticas mostradas en el portafolio.
